Operadores Aritméticos

+
Adição
Soma dois valores numéricos ou concatena strings.
let a = 10 + 5; // 15
let b = "Olá" + " JS"; // "Olá JS"
-
Subtração
Subtrai o segundo operando do primeiro.
let a = 10 - 3; // 7
let b = 0 - 5; // -5
*
Multiplicação
Multiplica dois valores numéricos.
let a = 4 * 3; // 12
let b = 2.5 * 2; // 5
/
Divisão
Divide o primeiro operando pelo segundo.
let a = 10 / 2; // 5
let b = 7 / 2; // 3.5
%
Módulo (Resto)
Retorna o resto da divisão inteira entre dois números.
let a = 10 % 3; // 1
let b = 8 % 4; // 0
**
Exponenciação
Eleva o primeiro operando à potência do segundo (ES2016+).
let a = 2 ** 8; // 256
let b = 3 ** 3; // 27
++
Incremento
Incrementa o valor em 1. Pode ser prefixo (++x) ou sufixo (x++).
let x = 5;
x++; // x agora é 6
++x; // x agora é 7
--
Decremento
Decrementa o valor em 1. Pode ser prefixo (--x) ou sufixo (x--).
let x = 5;
x--; // x agora é 4
--x; // x agora é 3

Operadores de Comparação

==
Igualdade (solta)
Compara valores após conversão de tipo (coerção). Evite usar — prefira ===.
5 == "5" // true ⚠️
0 == false // true ⚠️
===
Igualdade estrita
Compara valor E tipo, sem coerção. Recomendado sempre.
5 === 5 // true ✓
5 === "5" // false ✓
!=
Desigualdade (solta)
Retorna true se os valores são diferentes, com coerção de tipo.
5 != 3 // true
5 != "5" // false ⚠️
!==
Desigualdade estrita
Retorna true se valor OU tipo são diferentes. Recomendado.
5 !== "5" // true ✓
5 !== 5 // false ✓
>
Maior que
Verdadeiro se o operando esquerdo é maior que o direito.
10 > 5 // true
3 > 8 // false
>=
Maior ou igual
Verdadeiro se esquerdo é maior ou igual ao direito.
5 >= 5 // true
4 >= 5 // false
<
Menor que
Verdadeiro se o operando esquerdo é menor que o direito.
3 < 8 // true
9 < 4 // false
<=
Menor ou igual
Verdadeiro se esquerdo é menor ou igual ao direito.
5 <= 5 // true
6 <= 5 // false
// 04

Operadores Lógicos

&&
AND (E lógico)
Retorna o primeiro valor falsy ou o último valor se todos forem truthy.
true && true // true
true && false // false
5 && "Olá" // "Olá"
||
OR (OU lógico)
Retorna o primeiro valor truthy ou o último valor se todos forem falsy.
false || true // true
0 || "padrão" // "padrão"
1 || 99 // 1
!
NOT (NÃO lógico)
Inverte o valor booleano do operando. Dois !! convertem para boolean.
!true // false
!false // true
!!0 // false
??
Nullish Coalescing
Retorna o lado direito apenas se o esquerdo for null ou undefined (ES2020+).
null ?? "padrão" // "padrão"
0 ?? "padrão" // 0 ✓
undefined ?? 42 // 42

Outros Operadores

?:
Ternário
Forma compacta de if/else. Condição ? valor_verdadeiro : valor_falso.
const msg = idade >= 18
  ? "Maior"
  : "Menor";
?.
Optional Chaining
Acessa propriedade aninhada sem lançar erro se o objeto for null/undefined (ES2020+).
const zip = user?.address?.zip;
// undefined (sem erro!)
typeof
Tipo do valor
Retorna uma string indicando o tipo do operando.
typeof 42 // "number"
typeof "Olá" // "string"
typeof true // "boolean"
instanceof
Instância de
Verifica se um objeto é instância de uma classe ou construtor.
[] instanceof Array // true
{} instanceof Object // true
"x" instanceof Array // false
in
Propriedade existe
Retorna true se a propriedade especificada existe no objeto.
"nome" in {nome: "Ana"} // true
0 in [10, 20] // true
...
Spread / Rest
Espalha elementos de um iterável ou agrupa parâmetros restantes.
const b = [...a, 4, 5]; // spread
function f(...args) {} // rest
